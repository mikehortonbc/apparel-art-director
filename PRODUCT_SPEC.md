# PRODUCT SPEC (working source)

This MVP is an apparel creative-direction tool (not a generic AI image playground).

## Required first build
1. app shell
2. dashboard
3. new project workspace
4. rough prompt box at top
5. multi-step intake form
6. save/load draft JSON
7. review screen
8. prompt builder
9. feedback + revision flow
10. targeted edit prompt builder

## Product constraints
- Typography quality is central.
- Event art and retail art use different logic.
- Revisions must preserve what works.
- Targeted edits are different from full redesigns.
- Hidden typography system prompt must be editable in admin settings.
