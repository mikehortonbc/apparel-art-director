# PRODUCT_SPEC

This document defines the required product behavior for the apparel creative-direction workflow tool.

## Core workflow
1. Rough prompt input must drive workflow start.
2. Prompt-to-form autofill should extract likely details into intake fields.
3. Multi-step intake form captures structured project data.
4. Review screen summarizes captured project data.
5. Prompt builder must output:
   - master
   - short
   - stronger / bolder
   - safer commercial
   - typography-hero
   - creative director notes
6. Feedback + revision workflow should persist notes and allow rebuild.
7. Targeted edit prompt builder should create edit-specific prompts from chosen output.
8. Lock / unlock controls at field level and global level.
9. Version history with save and restore.
10. Presets for reusable project setups.
11. Admin settings including editable hidden typography system prompt.

## UX guardrails
- Product is a workflow tool, not a concept gallery shell.
- Data should persist locally between sessions.
