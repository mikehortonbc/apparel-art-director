# Apparel Art Director

A complete **Next.js App Router** project for building and evaluating apparel art-direction concepts.

## Features

- Curated concept grid with scores.
- Live search and multi-select filters.
- Save/favorite interactions per concept.
- Campaign brief capture form with client-side validation.
- API endpoint at `/api/artworks` with query filters.

## Run locally

```bash
npm install
npm run dev
```

## API usage

```bash
curl "http://localhost:3000/api/artworks?category=Sportswear&style=Pattern"
```
